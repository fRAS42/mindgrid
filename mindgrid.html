CFold / unfold branch
TTidy layout
Ctrl+Z / Ctrl+YUndo / redo
Ctrl+S / Ctrl+Shift+SSave / save as
Ctrl+OOpen a .sqlite file

Your map is stored in a real SQLite database (tables nodes and meta). In Chrome and Edge, Save writes straight back to the same file. Other browsers download a fresh copy. Work in progress is also kept in this browser between visits, but only the .sqlite file is your real backup. You can also drop a .sqlite file onto the window.
